Activity

P5 Work and Operations Management · Annex A.16 · agfoda:Activity · JSON Schema · /activities

The Activity entity shall represent an operation that has been carried out, such as ploughing, sowing, application of a plant protection product or a fertilizer, irrigation, harvesting or work in a building.

Constraints

  • At least one of cultivationPeriodId, regionId, siteId, animalGroupId is set (clause 8.5).
  • endsAt is not earlier than startsAt (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
