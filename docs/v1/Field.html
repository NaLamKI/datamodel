Field

P3 Fields and Geospatial Data · Annex A.9 · agfoda:Field · JSON Schema · /fields

The Field entity shall represent a single, contiguous parcel of land managed as part of the farm. It is a core geospatial entity.

Constraints

  • endsAt is not earlier than startsAt (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).

Unique

  • name within farmId.

Referenced by

Region.fieldId, Observation.fieldId, Data.fieldId
