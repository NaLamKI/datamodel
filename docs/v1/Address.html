Address

P1 Party, Users and Access · Annex A.4 · agfoda:Address · JSON Schema · /addresses

The Address entity shall store the physical address of an Organization or a Farm.

Constraints

  • Exactly one of organizationId, farmId is set (clause 8.1).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).

Referenced by

Organization.addressId, Farm.addressId
