SustainabilityIndicator

P13 Sustainability · Annex A.46 · agfoda:SustainabilityIndicator · JSON Schema · /sustainability-indicators

The SustainabilityIndicator entity shall represent a sustainability indicator.

Constraints

  • periodEnd is not earlier than periodStart (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
