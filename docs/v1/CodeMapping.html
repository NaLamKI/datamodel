CodeMapping

P14 Semantics and Interoperability · Annex A.47 · agfoda:CodeMapping · JSON Schema · /code-mappings

The CodeMapping entity shall record the correspondence between a canonical concept and a code of an external scheme.

Attributes

Constraints

  • validTo is not earlier than validFrom (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).

Unique

  • conceptUri, externalScheme, externalCode (the deployment); At most one mapping per conceptUri and externalScheme may set isPreferred..
