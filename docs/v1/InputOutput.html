InputOutput

P10 Economics · Annex A.35 · agfoda:InputOutput · JSON Schema · /input-outputs

The InputOutput entity shall be a generic container quantifying any resource that is consumed or produced.

Constraints

  • Exactly one of activityId, cultivationPeriodId, animalId, animalGroupId is set (V03).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
