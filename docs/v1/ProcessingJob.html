ProcessingJob

P12 Data Processing and Decision Support · Annex A.43 · agfoda:ProcessingJob · JSON Schema · /processing-jobs

The ProcessingJob entity shall represent a single run of a service and is the reference point of the provenance model.

Constraints

  • finishedAt is not earlier than startedAt (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
