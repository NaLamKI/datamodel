ProcessingService

P12 Data Processing and Decision Support · Annex A.42 · agfoda:ProcessingService · JSON Schema · /processing-services

The ProcessingService entity shall describe a service that can be invoked to process data.

Constraints

  • typeUri should be set where serviceType is CUSTOM (clause 8.12).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
