Result

P12 Data Processing and Decision Support · Annex A.45 · agfoda:Result · JSON Schema · /results

The Result entity shall store the output of a run.

Attributes

Constraints

  • validUntil is not earlier than validFrom (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
