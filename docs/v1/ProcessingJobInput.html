ProcessingJobInput

P12 Data Processing and Decision Support · Annex A.44 · agfoda:ProcessingJobInput · JSON Schema · /processing-job-inputs

The ProcessingJobInput entity shall record the data processed by a run.

Constraints

  • Exactly one of dataId, entityType and entityId is set (V03).
  • entityType, entityId are set together or not at all (clause 8.12).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
