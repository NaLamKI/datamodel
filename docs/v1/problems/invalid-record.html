The record does not conform to its schema

Problem type · HTTP 422 · https://datamodel.agrifooddata.org/v1/problems/invalid-record

A mandatory attribute is missing, an attribute has the wrong type or format, or an attribute the entity does not have was sent.

Reported as RFC 9457 problem details (application/problem+json); violations names the rules and attributes concerned.
