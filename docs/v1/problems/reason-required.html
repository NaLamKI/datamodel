A correction needs a reason

Problem type · HTTP 422 · https://datamodel.agrifooddata.org/v1/problems/reason-required

The change affects documentation referenced by a RegulatoryReport whose status is SUBMITTED or later. Such a change is made through the correction path and needs a reason, sent as Change-Reason; it is recorded in the AuditLog (clause 5.1 b)).

Reported as RFC 9457 problem details (application/problem+json); violations names the rules and attributes concerned.
