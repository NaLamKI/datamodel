An integrity rule is violated

Problem type · HTTP 422 · https://datamodel.agrifooddata.org/v1/problems/rule-violation

The record violates a rule of clause 12 of the Recommendation (V01 to V16) or a condition of clause 8. `violations` names the rule and the attributes concerned.

Reported as RFC 9457 problem details (application/problem+json); violations names the rules and attributes concerned.

AgriFoodData model 1.0.0-draft.3 · machine-readable specification of the Recommendation Data model for digital agriculture and farm management systems (draft, revision 3, proposed to ITU-T Study Group 20, 2026-07-29). In the event of a discrepancy between the Recommendation and this machine-readable specification or the ontology, the text of the Recommendation takes precedence (clause 8).
