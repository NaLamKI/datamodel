The record can no longer be changed

Problem type · HTTP 409 · https://datamodel.agrifooddata.org/v1/problems/immutable-record

A RegulatoryReport is immutable from SUBMITTED onwards (rule V15); a correction is a new report referencing it through supersedesReportId. Audit log entries are never changed.

Reported as RFC 9457 problem details (application/problem+json); violations names the rules and attributes concerned.
