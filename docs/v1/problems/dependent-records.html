Other records depend on this one

Problem type · HTTP 409 · https://datamodel.agrifooddata.org/v1/problems/dependent-records

The record cannot be deleted because other records refer to it. Operational records are withdrawn from use by a terminal status or an endsAt timestamp instead (clause 5.1 i)).

Reported as RFC 9457 problem details (application/problem+json); violations names the rules and attributes concerned.
