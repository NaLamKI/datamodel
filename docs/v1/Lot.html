Lot

P6 Products and Inventory · Annex A.21 · agfoda:Lot · JSON Schema · /lots

The Lot entity shall represent a quantity of a product treated as a single traceable unit. It is the core entity of traceability.

Constraints

  • At most one of originCultivationPeriodId, originAnimalGroupId is set (V13).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).

Unique

  • lotNumber within productId; together with the origin reference for own production.

Referenced by

StockMovement.lotId, AnimalEvent.lotId, Data.lotId, InputOutput.lotId
