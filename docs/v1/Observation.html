Observation

P9 Observations and Data · Annex A.31 · agfoda:Observation · JSON Schema · /observations

The Observation entity shall record the value of an observed property for a feature of interest at a stated time, in alignment with [ISO 19156] and [OGC SensorThings].

Constraints

  • Exactly one of regionId, fieldId, siteId, animalId, machineId is set (V03).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
