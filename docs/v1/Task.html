Task

P5 Work and Operations Management · Annex A.15 · agfoda:Task · JSON Schema · /tasks

The Task entity shall represent work that is planned or ordered and that has not yet been carried out. It may be addressed from the office to an operator, and it may arise from a recommendation produced by a processing service, thereby closing the digital twin control loop described in clause 7.1.

Constraints

  • At least one of cultivationPeriodId, regionId, siteId, animalGroupId should be set (clause 8.5).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
