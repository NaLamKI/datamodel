Economics

P10 Economics · Annex A.36 · agfoda:Economics · JSON Schema · /economics

The Economics entity shall attach a monetary value to a quantity, a stock movement or the deployment of a resource.

Constraints

  • Exactly one of inputOutputId, stockMovementId, activityResourceId is set (V03).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
