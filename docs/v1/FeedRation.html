FeedRation

P8 Animal Husbandry · Annex A.28 · agfoda:FeedRation · JSON Schema · /feed-rations

The FeedRation entity shall represent a planned ration for a group of animals.

Constraints

  • validTo is not earlier than validFrom (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
