ActivityResource

P5 Work and Operations Management · Annex A.17 · agfoda:ActivityResource · JSON Schema · /activity-resources

The ActivityResource entity shall record the deployment of a machine or of a person in an operation, resolving the many-to-many relationship between operations and resources. It is the basis for the attribution of machine costs and labour costs.

Constraints

  • Exactly one of machineId, workerId is set (V03).
  • machineId is set where resourceType is MACHINE (clause 8.5).
  • workerId is set where resourceType is WORKER (clause 8.5).
  • endsAt is not earlier than startsAt (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
