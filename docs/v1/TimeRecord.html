TimeRecord

P5 Work and Operations Management · Annex A.18 · agfoda:TimeRecord · JSON Schema · /time-records

The TimeRecord entity shall record working time, including time that is not attributable to a single operation, such as absence or leave.

Constraints

  • endsAt is not earlier than startsAt (V01).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
