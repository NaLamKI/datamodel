Data

P9 Observations and Data · Annex A.32 · agfoda:Data · JSON Schema · /data

The Data entity shall be a container for a dataset or a data stream, such as satellite imagery, laboratory reports, yield maps or imagery from unmanned aircraft. In this Recommendation, a dataset denotes a bounded collection of data recorded over a defined period and made available as one or more files, whereas a data stream denotes a continuously updated sequence of observations made available through an endpoint.

Constraints

  • Exactly one of regionId, fieldId, farmId, siteId, cultivationPeriodId, activityId, animalId, machineId, lotId is set (V03).

In addition, for every entity: createdByUserId is set where originType is USER, createdByJobId where it is SERVICE (V04).
